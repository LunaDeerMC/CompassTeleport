# CompassTeleport

使用指南针进行传送，增强原版指南针功能，更适合长途探险！

![](./images/img.png)

## 使用方法

1. 使用磁石绑定指南针；

2. 使用铁砧对指南针进行重命名；

3. 将命名后的指南针拿在手上；

4. 右键即可传送到磁石附近；

## 复制传送指南针

在铁砧左侧放入 **1 枚已激活的传送指南针**，右侧放入 **普通、未修改的指南针**，即可取出 **2 枚内容相同的传送指南针**。这会保留原指南针的名称、描述、磁石绑定位置、精确传送位置与朝向。

复制消耗右侧 1 枚普通指南针，等级费用沿用 `cost-level`。原指南针会随铁砧材料一同合成为结果中的两枚指南针；不支持左槽堆叠多枚来源指南针。

## 配置参考

```yaml
# 传送后的冷却时间 秒
cooldown-sec: 12

# 传送前的延迟时间 秒
delay-sec: 3

# 命名指南针的花费
cost-level: 1
```

## 权限节点

| 权限节点                | 说明   | 默认   |
|---------------------|------|------|
| compassteleport.use | 传送操作 | true |
